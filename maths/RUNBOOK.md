# SRJ EDU daily MATHS reel runbook (9 PM IST)

Suraj (2026-11-27): one new code-made maths reel every day, posted at **21:00 IST** on Instagram, Facebook
and YouTube through Buffer. Style follows his reference video: black background with a faint moving grid, glowing
white equations, bright colour-coded shapes, camera zooms, green progress bar, `@srj_edu_app` at the top.
English on-screen text. All sound is generated by code (`maths/sound.py`), no samples, no copyrighted music.
This is separate from the science "This vs That" reels in the root `RUNBOOK.md` (do not touch those).

A scheduled task runs this at about 7:20 PM IST. It must finish and schedule the posts before 21:00.

## 1. Setup
`pip install pycairo` (needs nothing else; fonts Inter and DejaVu Serif are already installed). Clone this repo.

## 2. Already done today?
If any topic in `maths/topics.json` has `status` starting with `scheduled <today>`, stop and report that.

## 3. Pick the topic (no repeats)
The topic is the first entry in `maths/topics.json` whose `status` is empty. Never reuse a topic whose status is set.
If fewer than 7 empty topics remain, append 15 new, correct, visual topics to the list (same fields), so the
queue never runs dry. Never add a topic that is already in the list under another name.

## 4. Write the topic module `maths/topics/<slug>.py`
Copy the shape of `maths/topics/odd_squares.py` and use the helpers in `maths/engine.py`
(`background`, `math_row`, `text`, `rect`, `circle`, `line`, `glow`, `flash`, `caption`, `chrome`,
camera via `set_camera` + `push_world`/`pop`, easing `prog`/`ease`/`ease_back`/`window`).
The module defines `TITLE`, `DURATION` (35-55 s), `WOW_AT`, `MUSIC_SEED` (= topic n mod 3), `draw(r, t)`,
`sfx()`, `YT_TITLE`, `CAPTION`, `HASHTAGS`, and a docstring listing every number it shows, each checked.

Story (always): **hook** in the first 1-3 s (frame 0 must already show the hook: it is the thumbnail) ->
**visual exploration** (shapes/graphs moving, not text) -> **step-by-step explanation** (equation morphs,
colour-coded to the shapes) -> **wow moment** at `WOW_AT` (riser ending there + boom + flash + particles) ->
**ending** with the general formula and a curiosity question ("Comment your answer below").

Rules:
- Every number, formula and graph must be correct. Compute values in Python, never type them from memory.
  If a fact cannot be verified, change the topic angle rather than guess.
- Keep important things between y = 250 and y = 1560 (safe area); captions at y 1500, max ~45 characters.
  `math_row` and `caption` shrink text to fit, but keep lines short anyway.
- Sound: a `click` or `pop` when a number or shape appears (rising `pitch` for sequences), `whoosh` on scene
  changes, `chime` when a result lands, `riser` + `boom` + `sparkle` at the wow. Gains 0.4-0.9.
- Make every animation explain something; no random motion.

## 5. Check, then render
`python3 -m maths.make <slug> /tmp/p --preview 0,2,<one time per scene>,<WOW_AT+0.5>,<DURATION-1>`
and look at every PNG. Fix overflow, overlap, wrong numbers, empty frames. Then:
`python3 -m maths.make <slug> reels/maths_NNN.mp4` (NNN = topic n, 3 digits; about 2-3 min).
Check `ffprobe`: 1080x1920, 30 fps, h264 + aac, duration = DURATION, size < 15 MB.

## 6. Publish the file
Commit `maths/topics/<slug>.py` and `reels/maths_NNN.mp4`, push to `main`.
URL: `https://raw.githubusercontent.com/srjs97/srj-edu-reels/main/reels/maths_NNN.mp4`;
`curl -sI` must give 200 and content-length > 1,000,000 (retry for up to 2 min after the push).
